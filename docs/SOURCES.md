- **unknown from public specifications:** whether every feature of this customized M2024C hardware/firmware works with the runtime. The separate local acquisition receipts determine which features actually passed.
- **unknown:** exact outer HinaLea model/revision, which physical cable is mapped to which interface, and whether COM4 is the FP controller. Enumeration alone does not establish the serial command grammar, baud rate, safe controller settings, status acknowledgement, or calibration.

### Local static package review, 2026-09-05

- **confirmed:** INF `DriverVer` is 2017-10-26 / 3.0.7.0; runtime package is 3.7.2. These are different versioned components. The MSI selects the SHA256EV files for Windows 10 or later.

The INF's exact SHA-256 matches its named entry in that signed catalog; direct INF Authenticode reports an unsupported-format error, which is recorded separately.

Static signatures and matching are not a successful driver installation.

## Remaining assets and next informative checks

1. **Imaging module:** the static signature, architecture and INF class-match review is complete. The main recovery subsequently received driver authorization and performed installation/acquisition work; consult its receipts for the current runtime and raw-frame results. The static review itself did not load the driver. No firmware or UserSet update is required by this evidence.
2. **Physical linkage:** map each observed interface to the physical instrument using its label and a user-performed, normal data-cable disconnect/reconnect snapshot where necessary. USB-A/USB-C shapes do not define signal purpose.
3. **Controller:** a legitimate TruScope/TruScope NRT installation or relevant SDK headers/examples/configuration for this hardware, or an authorized existing working control program plus its communication record. Required evidence includes open-session behavior, command framing, units/range, state acknowledgement and synchronization. Do not guess commands from an LPC microcontroller example.
4. **Spectrum:** device-matched wavelength vector plus the source of any required FP response/reconstruction model, full prescribed scan sequence, and calibration provenance. A Balluff camera XML or image-intensity LUT is not sufficient. Dark/white frames cannot supply the missing spectral mapping.
5. **Fallback study:** if original spectral calibration cannot be recovered, a separate measured spectral-response calibration using traceable/characterized wavelength sources and independent validation is needed. Its feasibility and accuracy are unknown; software alone cannot recreate missing physical calibration or guarantee factory performance.

No source in this register is authority to override the user's operational boundaries. Public documentation supports a next check; only local execution receipts support hardware PASS.
