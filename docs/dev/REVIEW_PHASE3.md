## Executed checks

The unchanged baseline passed 189 tests. Five targeted regressions were then run
before fixes and all five failed, including the deterministic F4 race. Private
receipts: `phase3/baseline-tests.log`, `reproductions.log` and their JUnit XML.
The first full changed suite yielded 208 passed / 1 failed: a MISSING prefix hid
PARTIAL status. The implementation was corrected and the next run passed 209.
Additional regressions reproduced a stale PCA chart after loading another file
and a destroy exception replacing the primary Stop error; both were fixed.
The final source suite passed **219 tests in 18.17 s** using offscreen Qt.
An earlier Windows-platform run passed 215 tests but emitted a handled native
0x8001010d exception trace; it is retained, not hidden. Its cause is unconfirmed.
The subsequent offscreen suite had no such trace. Two later regressions cover
GenApi continuous floats without a fixed increment and transport failure in the
increment-support query. Native desktop workflows are
separate evidence, not a substitute for the regression suite.

Targeted tests live in `tests/test_phase3_contracts.py`,
`tests/test_phase3_plots_and_portability.py` and `tests/test_camera_session.py`.
Existing analysis, precision, sequence, ENVI-independent-reader and Qt tests stay
in the suite. Two normalization tests now inspect the separate shape panel while
also checking preservation of raw amplitudes.

Figure comparisons use computed source values and exported CSV/NPY/PlotSpec,
not screenshots as numerical truth. Public examples are generated by
`python -m hyperlab figure-demo`; before/after desktop evidence is local.

The frozen-package smoke exposed an eager legacy Tk import; a subprocess test
now blocks Tk imports while checking the default Qt entry. An intermediate full
run reported 218 passes and one fixture failure: writer startup overflow preceded
the injected cable fault. That fixture now has room for all 12 possible fake
frames, isolating its intended fault. Production queue limits and separate
overflow/closing tests were unchanged.

## Remaining limits

Native call deadlines are observable, not cancellation guarantees. Terminating an
owned diagnostic helper still leaves device release NOT_CONFIRMED and does not
permit automatic retry. One unplanned native Open during desktop QA failed at
ExposureTime.GetInc(), with no acquisition. Its trigger and release limits are
recorded in the handoff. The correction was tested offline, with no native retry.
Other optional feature support remains subject to future explicit normal-session
readback. License and new-machine installation
qualification cannot be closed by offline tests.
