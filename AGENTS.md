# Contributor guidance

Inspect the actual branch and working tree; preserve existing changes. Read README
and the user method contracts before changing behavior. Keep changes scoped and
provide a focused reproduction for consequential fixes, followed by relevant tests.
UI and user documentation are English. Preserve raw data, failed/partial cases,
source/axis/units and complete denominators; software tests are not physical validation.
Keep captures, calibration, identifiers, vendor binaries and private development
records outside public source/package candidates. Stage exact reviewed paths.
Do not add a license, distribute vendor assets, merge or publish without the
appropriate owner authorization. Normal offline app use must not open hardware.
